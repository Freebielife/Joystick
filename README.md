# JOYSTICK Observatory

Обсерватория JOYSTICK (JSI) в одном самодостаточном `index.html` для TON Storage.
Этот репозиторий был создан из шаблона; теперь в нём настроенная обсерватория JSI.
Предыдущая версия шаблона сохранена в истории Git.

дивидендами в TON. Это заявление проекта, а не независимая проверка выплат.

## Исправление отсутствующих данных

TON API отдавал события пула как `SmartContractExec`, без `JettonSwap`.
Сборщик теперь читает успешные транзакции самого проверенного пула и его внешние
события `swap#9c610de3`: проверяет эмитента, пару TON/JSI, суммы и инициатора.
Официальная схема: https://docs.dedust.io/reference/tlb-schemes#event-swap
Запрос: https://tonapi.io/v2/blockchain/accounts/EQBLX8vWiUk8noyQEUy6ovLokfK6ToP_IVM5aVyaqRuxOQ7I/transactions

Суммы — исполненные объёмы обмена в пуле, без приложенного газа. Инициатор может
быть контрактом или маршрутизатором. Последующая доставка из хранилища получателю
не проверяется отдельной трассировкой. Пополнение/вывод ликвидности и неудачные
транзакции не считаются обменами. Лента, продавцы, объёмы и график используют
один и тот же сборщик; история догружается с сохранением курсора.

Оценка капитализации = TON за JSI в последнем обмене × текущее общее предложение.
Это оценка по пулу, не circulating market cap. Для USD используется история TON/USD.
Неполные периоды обозначаются явно; ошибка источника сохраняет последние исправные
данные и их время. Отсутствие источника не означает нулевую активность.

Метки сервисов используют справочник Tonkeeper и проверенные роли контрактов.
Домены, OG и +888 проверяются постепенно: непроверенным кошелькам метки не выдаются.
Спецметки чужих проектов, DEV, неподтверждённые NFT/стейкинг не перенесены.

## Сборка и проверка

```bash
python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.cjs
python3 -m scripts.refresh_observatory
python3 build.py
python3 verify.py
```

`VERIFICATION.json` фиксирует размер, SHA-256 и выполненные проверки этой сборки.
Функциональная DOM-проверка охватывает RU/EN, график TON/USD, фильтры, операции
10→50, держателей 10→20→10, продавцов, сервисы, копирование и внутренние ссылки.
В HTML нет внешних шрифтов, скриптов, стилей или изображений для отображения.
Сетевая загрузка снимка и ручной поиск кошелька требуют доступа к API.

Пройдены 36 Python-тестов и 15 Node-тестов. Настоящий Chrome в GitHub Actions
проверил ширины 320, 360, 393, 768 и 1440 px: переполнения по ширине нет, работают
RU/EN, график и клавиатурный курсор, копирование, фильтры и раскрытие списков.
Полные мобильный (393 px) и настольный (1440 px) снимки просмотрены визуально.
Проверка намеренно блокирует внешнюю сеть и подтверждает работу встроенных данных.
Raw-снимок и HTML из GitHub отдельно проверены: HTTP 200 и CORS `*`.
Прямые HTTP-проверки внешних Telegram/gram.org/DeDust ссылок получили 403 в этой
среде; доступность этих сайтов здесь не подтверждена.

При первом запуске в дополнительных проверках кошельков были HTTP 429. Добавлена
общая пауза 4,2 с между запросами сборщика. Раздел Authorization официальной
документации указывает один запрос за четыре секунды, отдельная страница о dApp
указывает 1 RPS; выбран более строгий вариант:
https://docs.tonapi.io/tonapi и https://docs.tonapi.io/tonapi/dapp/free-limits.
Это не исключает ограничений провайдера при разделяемом IP.

Успешный запуск сбора, браузерных проверок и публикации:
https://github.com/Freebielife/Joystick/actions/runs/45567292711
На момент проверки сохранены 1474 обмена за год (1028 покупок, 446 продаж),
327 держателей; `index.html` меньше 0,8 MB. Это данные снимка, не постоянные величины.

## Публикация и обновление

`update.yml` запускает сборщик при изменениях исходников, вручную и по расписанию
`17,47 * * * *` (UTC), то есть каждые 30 минут. GitHub может задерживать расписание.
Это отдельное расписание этого репозитория; общий Cloudflare runner не изменён.
Результат сохраняется в `data/snapshot.json` и `index.html` без force push.
Сайт проверяет новый снимок из этого репозитория каждые пять минут; при сетевой
ошибке остаётся встроенный снимок. Изменения оформления требуют нового HTML.

Для TON Storage нужен только `index.html`. Его загрузка и привязка TON-домена
не выполнены в этой работе: адрес опубликованного TON-сайта не предоставлен.
Публикация исходников в GitHub и размещение в TON Storage — отдельные действия.
Плановый запуск считается подтверждённым только после наблюдения события schedule.
